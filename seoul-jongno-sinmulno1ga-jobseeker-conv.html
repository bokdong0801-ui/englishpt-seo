수업 진행

설명만 듣고 끝나지 않게 이렇게 진행합니다

설명을 오래 듣는 순서보다 현재 행동을 확인하고, 직접 사용하고, 조건을 바꿔 다시 확인하는 흐름으로 진행합니다.

  1. 01
    직무와 면접 일정 확인

    직무와 면접 일정 확인 단계에서는 다음 실제 사용 순간에 무엇을 해야 하는지 행동 단위로 정합니다. 추상적인 실력보다 다음 상황의 결과를 수업 목표로 삼습니다.

    다음 상황에서 해야 할 행동이 선명하면 필요한 표현의 양도 줄일 수 있습니다. 실제 결과에 직접 연결되는 것부터 남깁니다.

  2. 03
    첫 답변 블록 만들기

    첫 답변 블록 만들기 단계에서는 설명을 들은 내용을 직접 질문·답변·설명으로 바꾸어 실제 사용 형태로 옮깁니다. 아는 것과 쓰는 것의 간격을 확인합니다.

    수업 안에서만 자연스러운 문장은 실제 사용 능력과 다를 수 있습니다. 직접 말하고 묻는 행동까지 가야 확인이 끝납니다.

  3. 05
    모의면접 후 다음 질문 기록

    모의면접 후 다음 질문 기록 단계에서는 수업 밖에서 시도할 한 문장이나 한 행동을 정합니다. 실제 사용 결과를 다음 시간에 가져와 계획을 다시 조정합니다.

    수업 밖 시도는 완벽할 필요가 없습니다. 한 문장을 실제로 써본 결과가 다음 수업의 가장 구체적인 자료가 됩니다.

좋은 문장을 외우는 것보다 질문을 조금 바꿔 다시 답해보는 과정이 중요합니다. 같은 구조를 다른 질문에서도 만들 수 있어야 실제 사용 범위가 넓어졌다고 보기 쉽습니다.

오답과 막힘은 원인별로 나눠 기록합니다

같은 실패처럼 보여도 지식 부족, 질문 이해, 시간 압박, 표현 회수, 답변 구조처럼 원인은 다를 수 있습니다. 원인이 다르면 다음에 반복할 연습도 달라져야 합니다.

정답 설명을 길게 옮기기보다 왜 그렇게 선택했는지 한 문장, 다음에는 무엇을 확인할지 한 문장 정도로 남깁니다. 새 자료에서 같은 원인이 다시 나타나는지가 실제 다시 확인 기준입니다.
