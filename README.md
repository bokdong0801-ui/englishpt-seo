# ENGLISH PT SEO

Production repository for the ENGLISH PT static SEO site.

- 95 final content pages
- 74 legacy permanent redirects
- Netlify selected as the production host
- Public deployment is intentionally paused until the final domain is chosen
- Current `https://englishpt.kr` references are placeholders only

When the domain is decided, run `python scripts/set-domain.py https://YOUR-DOMAIN`, review the generated changes, then connect `main` to Netlify and deploy.
