DETAILED INTRO

영어가 싫어서 미룬 게 아니라, 가족 일정과 하루 일과 속에서 내 공부가 자꾸 뒤로 밀렸던 건 아닐까요?

세종특별자치시 고운동에서 주부영어회화을 알아볼 때 과정 이름을 비교하기 전에 '내가 다음에 영어를 써야 하는 순간'부터 떠올려보세요.

비교 판단형에서는 이 수업이 무엇을 해주는가만 설명하지 않습니다. 지금 고민이 이 과정에 맞는지, 시험·학교영어·면접처럼 더 직접적인 다른 준비가 먼저인지 함께 구분합니다. 과정마다 결과 기준이 다르므로 상담에서는 교재보다 목표·마감·현재 가능한 행동을 먼저 확인하고, 무엇을 할지뿐 아니라 무엇을 당장 하지 않을지도 정합니다.

PRIORITY

목표·일정·행동을 같이 놓고 봅니다

가까운 일정, 현재 가능한 행동, 반드시 해야 하는 결과 세 가지를 함께 놓고 순서를 정합니다.

목적보다 먼저 실제 가능한 시간과 끊기지 않는 빈도를 정하고, 생활에서 다시 쓸 표현부터 남깁니다.

자격시험이나 학교 성적처럼 정해진 평가가 목표라면 생활회화보다 해당 평가 준비를 먼저 봅니다.

CLASS FLOW

준비→재현→변형 순서로 진행합니다

준비한 답을 그대로 반복하기보다 장면을 조금씩 바꾸면서 같은 기준을 재사용합니다.

  1. 01
    다시 시작하는 이유 확인

  2. 02
    현재 기억나는 표현 확인

    현재 기억나는 표현 확인은 필요한 기능과 불필요한 범위를 구분하는 단계입니다.

  3. 03
    짧은 생활 문장 사용

    짧은 생활 문장 사용에서는 실제 결과 기준에 직접 연결되는 문장만 남깁니다.

  4. 04
    일상 장면을 바꿔 반복

    일상 장면을 바꿔 반복은 다른 조건에서도 쓸 수 있는지 비교하는 과정입니다.

  5. 05
    다음 주 가능한 시간으로 연결

    다음 주 가능한 시간으로 연결 결과를 보고 다음 과정 유지·전환 여부를 정합니다.
