DETAILED INTRO

영어가 싫어서 미룬 게 아니라, 가족 일정과 하루 일과 속에서 내 공부가 자꾸 뒤로 밀렸던 건 아닐까요?

서울특별시 서초구 내곡동에서 주부영어회화을 알아볼 때 검색어보다 먼저, 지금 막히는 장면을 한 가지 고르면 페이지가 훨씬 단순해집니다.

장면 기록형에서는 최근 일주일 안에 실제로 멈춘 순간을 기준으로 시작합니다. 기억나는 문장 하나, 상대가 던진 질문 하나, 답을 바꾸고 싶었던 순간 하나만 있어도 충분합니다. 완벽한 레벨테스트보다 실제 장면이 더 정확한 출발점이 될 때가 많습니다. 이미 혼자 처리되는 부분은 유지하고, 멈추는 지점 앞뒤만 잘라 연습합니다. 기록은 어떤 조건에서는 됐고 어떤 조건에서는 아직 멈췄는지를 남깁니다.

CLASS FLOW

이렇게 수업에서 확인합니다

수업은 설명을 오래 듣는 순서가 아니라, 확인한 내용을 바로 써보고 다시 확인하는 흐름으로 갑니다.

  1. 01
    다시 시작하는 이유 확인

    다시 시작하는 이유 확인 단계에서는 현재 가능한 범위를 과장하지 않고 짧게 봅니다.

  2. 02
    현재 기억나는 표현 확인

    현재 기억나는 표현 확인에서는 설명보다 직접 만들어보는 시간을 더 둡니다.

  3. 03
    짧은 생활 문장 사용

    짧은 생활 문장 사용부터 익숙한 문장 단서를 줄입니다.

  4. 04
    일상 장면을 바꿔 반복

    일상 장면을 바꿔 반복에서는 질문이나 순서를 바꿔도 기준이 남는지 봅니다.

  5. 05
    다음 주 가능한 시간으로 연결

    다음 주 가능한 시간으로 연결 결과를 다음 수업 첫 확인 항목으로 연결합니다.
