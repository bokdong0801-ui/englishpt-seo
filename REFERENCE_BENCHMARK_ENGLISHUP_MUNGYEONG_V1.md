## Proof policy
Real review or outcome claims require actual evidence.
If evidence is not available:
- label examples as illustrative
- use observable process/behavior
- never invent score gains, rankings, student quotes, or time-to-result promises

## Production principle
A page does not pass because it is long.
It passes only when the reader can answer:
1. What exact problem is this page about?
2. Why does that problem happen?
3. What does ENGLISH PT look at?
4. What does the training actually do?
5. How is progress rechecked?
6. Is this page the right path for me?
7. What will be discussed if I request consultation?
