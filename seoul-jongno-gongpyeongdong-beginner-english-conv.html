다음 실제 사용 상황에서 인사와 자기소개를 어떻게 해야 하는지 한 문장으로 먼저 정합니다. 결과가 분명하면 연습 자료와 문장 길이를 과하게 늘릴 필요가 없습니다.

어려운 이유

왜 어려운지 알면 연습 방법도 달라집니다

사용 상황은 구체적일수록 좋습니다. '회화를 잘하고 싶다'보다 '발표 후 질문 두 개에 짧게 답해야 한다'처럼 결과가 보이면 수업 안에서 무엇을 재현할지도 명확해집니다.

같은 결과가 반복돼도 원인이 항상 같지는 않습니다. 현재 가능한 범위, 도움을 줬을 때의 변화, 조건을 바꾼 뒤 다시 되는지를 나눠 기록하면 다음 연습을 과하게 넓히지 않을 수 있습니다.

먼저 준비할 것

모든 걸 한꺼번에 하지 않고, 먼저 할 것부터 정합니다

다음 실제 사용 상황에서 꼭 필요한 행동부터 정하고 그 행동을 가능하게 하는 기초만 역산합니다. 직접 연결되지 않는 범위는 뒤로 미룰 수 있습니다.

시험 점수나 면접 일정이 급하다면 왕초보 회화 전체보다 해당 목표에 필요한 표현을 먼저 보는 편이 직접적일 수 있습니다.

  • 인사·자기소개 한두 문장
  • be동사와 기본 문장 구조
  • 짧은 질문을 듣고 한 문장으로 답하기

우선순위는 고정하지 않습니다. 일정과 실제 결과가 바뀌면 이미 안정된 항목의 반복은 줄이고 다음에 필요한 행동으로 비중을 옮깁니다.

수업 진행

설명만 듣고 끝나지 않게 이렇게 진행합니다

설명을 오래 듣는 순서보다 현재 행동을 확인하고, 직접 사용하고, 조건을 바꿔 다시 확인하는 흐름으로 진행합니다.

  1. 03
    소리 내어 반복

    소리 내어 반복 단계에서는 설명을 들은 내용을 직접 질문·답변·설명으로 바꾸어 실제 사용 형태로 옮깁니다. 아는 것과 쓰는 것의 간격을 확인합니다.

    수업 안에서만 자연스러운 문장은 실제 사용 능력과 다를 수 있습니다. 직접 말하고 묻는 행동까지 가야 확인이 끝납니다.

  2. 04
    질문을 바꿔 다시 답하기

    질문을 바꿔 다시 답하기에서는 장소나 상대가 달라졌을 때도 같은 기능을 다시 적용할 수 있는지를 확인합니다. 한 상황 전용 문장으로 끝나지 않게 합니다.

    같은 기능을 다른 장소와 상대에게 옮겨 쓰면 상황 전용 암기인지 실제 사용 가능한 표현인지 구분하기 쉽습니다.

  3. 05
    짧은 복습으로 연결

    짧은 복습으로 연결 단계에서는 수업 밖에서 시도할 한 문장이나 한 행동을 정합니다. 실제 사용 결과를 다음 시간에 가져와 계획을 다시 조정합니다.

    수업 밖 시도는 완벽할 필요가 없습니다. 한 문장을 실제로 써본 결과가 다음 수업의 가장 구체적인 자료가 됩니다.

변화 확인

잘하고 있는지는 이렇게 확인합니다

막연한 '맞춤수업'이라는 말 대신 상담 전에도 확인할 수 있는 행동 기준을 공개합니다.

  • 기본문장도움이 있을 때와 없을 때 차이를 확인합니다.
  • 질문 이해질문이나 문장이 바뀌어도 기준이 유지되는지 봅니다.
  • 한 문장 답변다음 실제 일정과 직접 연결되는지 확인합니다.

자주 묻는 질문

상담 전에 많이 물어보는 내용

복습은 어떻게 하나요?

수업에서 사용한 짧은 문장을 다시 말하거나 녹음하고, 다음 수업에서 질문을 조금 바꿔 다시 답해봅니다.

알파벳만 아는 수준도 가능한가요?

현재 읽기와 듣기 수준을 먼저 확인하고 필요한 경우 아주 짧은 기초 문장부터 시작할 수 있습니다.

수업 밖에서 꼭 사용해야 하나요?

가능하다면 실제 상황에서 한두 가지를 시도해보는 것이 좋습니다. 사용이 어려운 기간에는 수업 안에서 조건을 더 실제처럼 바꿔 재현합니다.

오답의 이유

문제를 많이 푸는 것보다 같은 실수가 왜 반복되는지 구분하는 과정이 먼저일 수 있습니다. 공평동에서 왕초보영어회화를 비교한다면 정답 개수뿐 아니라 틀린 이유를 설명할 수 있는지도 함께 확인해보세요.

수업 비교 기준

수업을 비교할 때는 이런 부분을 확인해보세요

단어는 아는지보다 문장 안에서 다시 꺼낼 수 있는지 봅니다

뜻을 보고 아는 단어와 듣거나 말할 때 바로 나오는 단어는 다를 수 있습니다. 현재 목표에 자주 필요한 표현을 문장 안에서 사용하고 며칠 뒤 다시 꺼내보는 방식으로 확인합니다.

단어 목록을 무작정 늘리기보다 실제 문제·답변·글에서 반복해서 막히는 표현을 우선합니다. 이미 안정적으로 쓰는 표현은 유지 확인만 하고 새로운 표현과 혼동되는 부분에 시간을 더 씁니다.

쓰기는 글 피드백을 읽는 데서 끝내지 않고 다시 써봅니다

수정된 문장을 이해해도 새 주제에서 같은 오류가 반복될 수 있습니다. 논리, 문단 역할, 근거의 구체성, 표현 오류 가운데 반복되는 항목을 골라 직접 고쳐서 다시 쓰기합니다.

고쳐서 다시 쓰기 뒤에는 다른 문제에서도 같은 기준을 적용합니다. 글 피드백 횟수보다 스스로 수정할 수 있는 범위가 넓어지는지가 다음 학습 비중을 정하는 자료가 됩니다.

말하기는 녹음으로 첫 반응과 반복 패턴을 확인할 수 있습니다

말하는 동안에는 공백, 반복 표현, 답변 길이를 스스로 정확히 느끼기 어렵습니다. 짧게 녹음해 첫 문장까지 걸린 시간과 중간에 끊긴 지점을 표시하면 수정 기준이 구체적으로 보입니다.

좋은 문장을 외우는 것보다 질문을 조금 바꿔 다시 답해보는 과정이 중요합니다. 같은 구조를 다른 질문에서도 만들 수 있어야 실제 사용 범위가 넓어졌다고 보기 쉽습니다.
