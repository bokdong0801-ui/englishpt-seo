자기소개

자기소개는 외웠지만 질문 표현이 달라지면 시작 문장이 흔들립니다

다음 실제 사용 상황에서 자기소개를 어떻게 해야 하는지 한 문장으로 먼저 정합니다. 결과가 분명하면 연습 자료와 문장 길이를 과하게 늘릴 필요가 없습니다.

현재 가능한 범위를 확인한 뒤 자기소개에 직접 연결되는 문장과 질문만 먼저 사용합니다. 필요한 기초를 보더라도 다음에 연습할 내용과 어떻게 이어지는지 설명할 수 있어야 합니다.

연습 뒤에는 '배웠다'로 끝내지 않고 다음 자기소개 상황에서 시도할 첫 문장이나 확인 질문을 정합니다. 실제 사용 결과를 다음 수업의 첫 자료로 가져옵니다.

다음 실제 사용 상황에서 지원동기·직무 연결을 어떻게 해야 하는지 한 문장으로 먼저 정합니다. 결과가 분명하면 연습 자료와 문장 길이를 과하게 늘릴 필요가 없습니다.

어려운 이유

왜 어려운지 알면 연습 방법도 달라집니다

사용 상황은 구체적일수록 좋습니다. '회화를 잘하고 싶다'보다 '발표 후 질문 두 개에 짧게 답해야 한다'처럼 결과가 보이면 수업 안에서 무엇을 재현할지도 명확해집니다.

같은 결과가 반복돼도 원인이 항상 같지는 않습니다. 현재 가능한 범위, 도움을 줬을 때의 변화, 조건을 바꾼 뒤 다시 되는지를 나눠 기록하면 다음 연습을 과하게 넓히지 않을 수 있습니다.

먼저 준비할 것

모든 걸 한꺼번에 하지 않고, 먼저 할 것부터 정합니다

다음 실제 사용 상황에서 꼭 필요한 행동부터 정하고 그 행동을 가능하게 하는 기초만 역산합니다. 직접 연결되지 않는 범위는 뒤로 미룰 수 있습니다.

TOEIC Speaking·OPIc 등 제출 점수가 가장 급하다면 시험 형식에 맞춘 준비가 먼저입니다. 취업 면접이 아니라 여행·일상 대화가 목표라면 일반 성인 회화 과정이 더 직접적입니다.

  • 채용 마감과 면접 날짜 확인
  • 제출 점수가 급하면 시험 준비
  • 일상 회화 목적이면 일반 성인회화

우선순위는 고정하지 않습니다. 일정과 실제 결과가 바뀌면 이미 안정된 항목의 반복은 줄이고 다음에 필요한 행동으로 비중을 옮깁니다.

수업 진행

설명만 듣고 끝나지 않게 이렇게 진행합니다

설명을 오래 듣는 순서보다 현재 행동을 확인하고, 직접 사용하고, 조건을 바꿔 다시 확인하는 흐름으로 진행합니다.

  1. 02
    경험 근거를 짧게 정리

    경험 근거를 짧게 정리에서는 그 행동에 꼭 필요한 표현과 기초만 골라 바로 써볼 수 있는 형태로 정리합니다. 진도보다 실제 사용 연결을 먼저 봅니다.

    기초 설명이 필요해도 실제로 해야 하는 내용과 연결해 봅니다. 왜 이 표현을 배우는지 다음 상황에서 설명할 수 있어야 합니다.

  2. 03
    첫 답변 블록 만들기

    첫 답변 블록 만들기 단계에서는 설명을 들은 내용을 직접 질문·답변·설명으로 바꾸어 실제 사용 형태로 옮깁니다. 아는 것과 쓰는 것의 간격을 확인합니다.

    수업 안에서만 자연스러운 문장은 실제 사용 능력과 다를 수 있습니다. 직접 말하고 묻는 행동까지 가야 확인이 끝납니다.

  3. 04
    꼬리질문으로 흔들어 보기

    꼬리질문으로 흔들어 보기에서는 장소나 상대가 달라졌을 때도 같은 기능을 다시 적용할 수 있는지를 확인합니다. 한 상황 전용 문장으로 끝나지 않게 합니다.

    같은 기능을 다른 장소와 상대에게 옮겨 쓰면 상황 전용 암기인지 실제 사용 가능한 표현인지 구분하기 쉽습니다.

잘하고 있는지는 이렇게 확인합니다

  • 경험 근거도움이 있을 때와 없을 때 차이를 확인합니다.

  • 답변 길이이미 안정된 부분은 반복을 줄일 수 있는지 봅니다.

자주 묻는 질문

상담 전에 많이 물어보는 내용

OPIc이나 토익스피킹도 같이 준비하나요?

제출 점수가 급하면 해당 시험 형식에 맞춘 준비가 우선입니다. 면접 준비와 시험 준비는 질문 목적과 평가 기준이 다르므로 일정에 따라 비중을 나눕니다.

상담에서 목표를 정확히 말해야 하나요?

완벽한 목표 문장이 없어도 됩니다. 다음에 영어를 써야 하는 순간과 그때 하고 싶은 행동만 말해도 연습 범위를 좁힐 수 있습니다.

수업 밖에서 꼭 사용해야 하나요?

가능하다면 실제 상황에서 한두 가지를 시도해보는 것이 좋습니다. 사용이 어려운 기간에는 수업 안에서 조건을 더 실제처럼 바꿔 재현합니다.

단어 목록을 무작정 늘리기보다 실제 문제·답변·글에서 반복해서 막히는 표현을 우선합니다. 이미 안정적으로 쓰는 표현은 유지 확인만 하고 새로운 표현과 혼동되는 부분에 시간을 더 씁니다.

상담에서는 같은 질문으로 여러 곳을 비교해보세요

현재 목표, 가장 가까운 일정, 최근 어려웠던 상황 세 가지를 같은 기준으로 설명하면 과정마다 무엇을 다르게 제안하는지 비교하기 쉽습니다. 자료는 한두 개만 있어도 충분합니다.

등록을 바로 결정하기보다 진단 기준, 수업 흐름, 수업 밖 피드백, 다시 확인 방식이 얼마나 구체적으로 설명되는지를 확인하세요. 비교 기준이 같아야 가격과 횟수의 차이도 해석하기 쉬워집니다.
