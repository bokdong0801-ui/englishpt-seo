# ENGLISH PT v23.5.2 | 초·중·고 영어과외 학부모 상담 전환형 설계 확정

> 상태: Review 전용 콘텐츠 기획. v23.5.1 Production 배포 후보 원본은 변경하지 않음.
> 적용 범위: 6,060개 지역 × 초등·중등·고등 영어과외 3종 = 18,180개 상세페이지.
> **제외 범위**: 초·중·고 영어회화, 시험영어, 성인영어, 공통 허브, 상담 수집 시스템, canonical, OG 이미지, 사이트맵 및 robots.txt.

## 1단계 — 학부모가 상담 전 꼭 알고 싶은 5가지

- **우리 아이의 출발점**: 어휘 문제인지, 문장 구조인지, 읽고 이해하는 힘인지, 시험 적용인지 구분
- **학년별 차이**: 같은 초등·중등·고등 범위에서도 학년·목표·수준에 따라 우선순위 달라짐
- **실제 한 번의 수업**: 진단 → 개념 설명 → 학생 풀이 → 오답 원인 → 확인 과제
- **오답과 복습 관리**: 틀린 이유의 기록과 다음 수업의 재확인 기준
- **학부모 확인 포인트**: 아이가 직접 할 수 있게 된 변화와 남은 약점을 어떻게 살펴볼지

### 초등 영어과외 — '기초 수준에 맞는 학교 영어와 공부 습관'

초1~3: 알파벳·파닉스·읽기 기초가 필요한지 확인하되 모두에게 일률적으로 적용하지 않음. 짧은 낱말과 문장 읽기, 혼자 시작하는 복습 습관.
초4~5: 어휘를 문장에서 해석하고 주어·동사·시제 등 기초를 활용. 교과 지문을 이해하고 스스로 설명.
초6: 중학교 진입 전 긴 문장, 본문 해석, 문법 용어와 자기주도 복습 점검. 선행 진도보다 현재 이해 우선.
학생 예시: 교과 문장 속 주어·동사와 뜻 설명이 막힌 곳을 지도하고, 다음 시간 다른 문장에 적용하는지 확인.
학부모 판단: 파닉스 반복이 필요한지, 교과 문장 풀이가 필요한지 시작점을 구분할 수 있는가.

### 중등 영어과외 — '학교 자료·시험 범위와 서술형'

중1: 교과서 문장, 품사·시제·어순·기본 서술형으로 학교 영어 출발점 만들기.
중2: 길어진 본문·문법 응용과 문장 변형 서술형. 최근 시험의 문항별 오답 원인 파악.
중3: 중학교 내신 관리와 고1 독해의 연결. 학교 평가를 유지하며 구문 해석 취약점 정리.
시험 4주 전: 범위·자료·취약점 확인 → 2주 전: 문법·본문 적용 및 서술형 → 직전: 오답 재확인. **예시이며 학교별 일정·수준에 따라 달라짐.**
학생 예시: 틀린 서술형 시제와 어순을 구분하고 같은 오류가 새 문장에서도 반복되는지 확인.
학부모 판단: 단순 문제량이 아니라 정답을 고른 근거와 틀린 원인을 학생이 말할 수 있는가.

### 고등 영어과외 — '내신과 수능 독해를 분리한 우선순위'

고1: 중학교 학습에서 넘어온 어휘·구문 약점을 점검하고 교과·부교재 내신 대응.
고2: 모의고사 빈칸·순서·삽입·어법 약점을 유형별로 분리. 학교 시험 기간과 수능 유형 복습 비중 조정.
고3: 남은 일정·목표·최근 모의고사 데이터를 고려해 취약 유형과 풀이 시간 재점검.
수준별: 기초가 흔들리는 학생은 어휘·구문 정확도, 독해 내용은 이해하지만 시간 부족이면 유형별 접근부터. 점수·등급 단정 금지.
학생 예시: 빈칸 오답이 어휘 문제인지 글 전개 파악 실패인지 구분하여 새 지문으로 점검.
학부모 판단: 내신 자료와 모의고사를 같은 방법으로 공부하지 않고 목표에 따라 비중 조정하는가.

## 3단계 — 콘텐츠 품질·배포 기준

1. 6,060개 지역의 과외 3종 **18,180개만 수정**. 다른 140,391개 HTML을 읽거나 쓰지 않음.
2. 이미 있는 HTML 섹션의 순서와 안전한 CSS 스타일을 유지하며 '학년별 → 1회 수업 예시 → 오답/학부모 피드백 → 시험 대비(중·고) → FAQ'를 의미 순서대로 보강.
3. 새 FAQ는 기존 3개와 내용이 겹치지 않게 3개 추가. 기존·신규 합계 6개.
4. 기존 Hero, 상담 CTA, 상담폼, 학생영어 6개 지역별 버튼, OG·canonical·구조화 데이터 JSON-LD, 지역명 및 지역 간 네비게이션은 변경하지 않음.
5. 실제 학생의 성적·후기·수업 횟수·시간·학부모 피드백 제공 주기를 근거 없이 약속하거나 특정 학교 자료를 보유한다고 표현하지 않음.
6. 상담은 '실제 가능한 교재·숙제·피드백 방식을 확인하는 자리'로 설명. 구체 예시는 **'설명용 예시'**를 분명히 밝힘.
7. 소규모 HTML 샘플 및 전체 파일 전수 QA를 통과한 다음에만 Review 후보 확정. **Production/HOSTING/Netlify Draft 자동 배포 금지.**

## 상담 전환 판단 기준

학부모가 페이지를 읽고 ‘우리 아이는 무엇 때문에 어려워하는가’, ‘한 번의 수업에서 무엇을 하나’, ‘학년에 맞게 무엇이 달라지나’, ‘오답이 어떻게 다음 공부로 연결되나’, ‘상담에서 무엇을 물어볼 수 있나’에 답할 수 있어야 한다.
